# GiftQuest — Тайный Санта

Учебный интерактивный сайт на **HTML, CSS, Bootstrap 5.3.3, JavaScript и jQuery 3.7.1**, доработанный на основе предоставленного проекта. Шесть страниц, русский и английский языки, светлая и тёмная темы, 36 идей подарков с отдельными реалистичными изображениями.

## Публичная версия

[Открыть GiftQuest](https://fara1009.github.io/giftquest/)

Ветка `main` содержит проект; GitHub Pages публикует корень ветки `gh-pages`. При обновлении перенесите содержимое `dist/` в корень `gh-pages`, сохранив `.nojekyll`.

## Запуск

Распакуйте архив целиком, откройте папку `GiftQuest/dist` и дважды нажмите `index.html`. Python, сервер и интернет не нужны. Сохраняйте все файлы и папку `assets` рядом с HTML-страницами.

Для запуска через локальный сервер по-прежнему можно использовать `start.cmd` или Live Server в VS Code. На сервере каталог и переводы загружаются из JSON, при открытии файла — из включённой в проект копии `assets/local-data.js`. После изменения JSON обновите эту копию командой `node build-local-data.cjs` из папки проекта.

## Как пользоваться

1. Создайте игру: название, бюджет, дата обмена и срок анкет.
2. Добавьте 3–12 участников, заполните их интересы, предпочтения и исключения.
3. Проведите жеребьёвку. Каждый получает одного другого участника, без повторных получателей.
4. В разделе «Мой получатель» выберите участника и откройте его конверт.
5. Изучите рекомендации с объяснениями или используйте поиск, категории и сортировку каталога.
6. Сохраните идею, выберите подарок, отметьте подготовку, упаковку и вручение.

Для короткой демонстрации нажмите «Попробовать пример»: появятся пять вымышленных участников с готовыми анкетами. Существующая игра заменяется только после подтверждения в самом сайте.

## Что обновлено

- Тёмная палитра для всех страниц, форм, меню, карточек, уведомлений и диалогов. Первый запуск учитывает системную тему, затем действует сохранённый выбор. Тема применяется до отрисовки стилей и синхронизируется между вкладками одного адреса.
- Реалистичные изображения главной и конверта; отдельная фотографическая иллюстрация для каждой из 36 идей. Локальные WebP, явные размеры и lazy loading каталога.
- Перевод новых кнопок и описаний изображений на RU/EN; язык сохраняется после перезагрузки.
- Адаптированная навигация, видимый фокус, контрастная палитра, удобные кнопки и учёт reduced motion.
- Сохранены механики игры, проверки ввода, рекомендации, избранное, чек-лист и резервные копии.

## Алгоритмы, которые нужно понимать

**Жеребьёвка:** Фишер — Йетс перемешивает получателей. При самоназначении повторяем попытку, максимум 200 раз; запасной вариант — циклический сдвиг. Web Crypto даёт случайные числа. validDraw проверяет уникальность получателей и отсутствие самоназначений.

**Рекомендации:** сначала исключаем подарки выше бюджета и нежелательные категории. Совпадение интереса даёт 5 баллов, формата — 2. Сортируем по баллам, цене и ID. Объяснения формируются по фактическим совпадениям. Это алгоритм правил, а не ИИ.

**Хранение:** ключ `giftquest.game.v1` содержит JSON игры; язык — `giftquest.language`, тема — `giftquest.theme`. Импорт проверяется перед сохранением. Текст пользователя экранируется перед вставкой в HTML.

**Тема:** скрипт в head читает localStorage или prefers-color-scheme, задаёт data-theme на html. CSS-переменные меняют палитру всего сайта. Форма не перерисовывается, поэтому смена темы не теряет черновик. При недоступном хранилище тема работает в текущей вкладке и показывается сообщение.

**Перевод:** словарь содержит одинаковые ключи ru/en. t(key) выбирает перевод. Переключение языка обновляет интерфейс и форматирование, сохраняет черновики форм. Собственные имена и введённые пожелания не переводятся.

## Сценарий защиты: 5–6 минут

1. Объясните задачу: организовать обмен и помочь выбрать личный подарок. Покажите главную.
2. Смените тему и язык, обновите страницу. Покажите сохранённый выбор и мобильное меню.
3. Продемонстрируйте ошибку пустого названия или неверного бюджета. Загрузите пример игры.
4. Откройте анкету, объясните интересы и исключения. Сохраните пожелания, проведите жеребьёвку.
5. Откройте конверт и объясните рекомендации. Покажите поиск, ограничение цены и окно деталей.
6. Сохраните идею, выберите подарок, отметьте чек-лист. Обновите страницу — прогресс остаётся.
7. Назовите ограничения localStorage и объясните одну функцию из engine.js или theme.js.

Если работает команда, каждый должен назвать только свой фактический вклад и понимать соответствующую часть кода.

## Теория для подготовки

- **Bootstrap и CSS:** сетка Bootstrap управляет колонками и отступами; собственный CSS отвечает за визуальный стиль и специальные адаптивные правила.
- **DOM и события:** DOM — дерево документа. `$(document).on('click', selector, handler)` работает и для элементов, добавленных после загрузки.
- **JSON и асинхронность:** данные приходят не мгновенно. Promise.all ждёт оба файла, затем запускает интерфейс; при ошибке есть повторная загрузка.
- **localStorage:** хранит строки в конкретном браузере и origin. JSON.stringify/parse преобразуют объект. Это не серверная база и не система аккаунтов.
- **Валидация:** кроме типа HTML-поля нужны правила проекта — диапазон бюджета, порядок дат, минимум участников и отсутствие дубликатов.
- **Доступность:** семантика, подписи, клавиатура, alt, ARIA и контраст. Цвет не должен быть единственным сигналом.
- **CSS и JS:** CSS анимирует изменение внешнего вида; JS обрабатывает действие, меняет состояние и сохраняет данные.

## Проверки

Запустите `node checks.cjs`. Проверяются 1000 жеребьёвок для 3–12 человек, запасной вариант, бюджет и исключения, даты, 36 идей и фотографий, паритет RU/EN, локальные ресурсы и тема. Проверки темы учитывают перезагрузку, системный выбор, явный выбор пользователя, синхронизацию вкладок и недоступный localStorage.

В браузере проверены создание игры и ошибки ввода, дубликаты, анкета, смена языка с черновиком, жеребьёвка, получатель, избранное, выбор подарка, чек-лист после перезагрузки, поиск, фильтры, сортировка, dialog/Escape и мобильное меню. Все 6 страниц проверены на ширине 360 px; главная дополнительно на 320, 768, 1024 и 1440 px.

## Ограничения и публикация

Это учебная демонстрация в одном браузере: нет сервера, личных аккаунтов и синхронизации между телефонами. Переключение участников открыто для демонстрации, поэтому результаты не защищены от других пользователей того же браузера. Для настоящей приватной игры понадобится серверная версия.

Копия игры содержит анкеты и назначения. Очистка данных браузера удалит игру; на другом домене или порту будет отдельное хранилище. Для переноса используйте экспорт и восстановление.

Цены примерные. Все реалистичные изображения созданы встроенным Imagegen и иллюстрируют идеи; это не товары конкретного магазина.

Для GitHub Pages загрузите **содержимое `dist`** в публикуемую папку репозитория, чтобы index.html лежал в её корне. Относительные ссылки поддерживают адрес `/giftquest/`. Исходный сайт пользователя на GitHub автоматически не заменялся.
