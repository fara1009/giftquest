# GiftQuest — Тайный Санта

Двуязычный учебный сайт на HTML, CSS, Bootstrap 5.3.3, JavaScript и jQuery 3.7.1. Русский язык открывается по умолчанию. Данные игры сохраняются только в текущем браузере.

## Публичная версия

[Открыть GiftQuest](https://fara1009.github.io/giftquest/)

Ветка `main` содержит исходники и инструкции. GitHub Pages публикует содержимое ветки `gh-pages` из корневой папки. При обновлении сайта перенесите содержимое `dist/` в корень `gh-pages`, сохранив файл `.nojekyll`.

## Запуск

В Windows запустите `start.cmd`. Он использует Python, открывает браузер и запускает локальный сервер по адресу http://127.0.0.1:8766. Окно сервера нужно оставить открытым. Остановить: Ctrl+C.

Другой вариант: открыть папку `dist` расширением Live Server в VS Code. Или выполнить `python -m http.server 8766 --bind 127.0.0.1 --directory dist` из папки проекта.

Не открывайте HTML двойным щелчком: каталог и переводы загружаются из JSON, для этого нужен HTTP-сервер. Все библиотеки и изображения находятся в проекте; после запуска локального сервера внешние сервисы не нужны.

## Что работает

- Одна игра: название, бюджет в тенге, дата обмена и срок заполнения анкет.
- От 3 до 12 участников, проверка имён и дубликатов.
- Анкеты: 1–5 интересов, предпочтения, нежелательные категории, пожелания и записка.
- Жеребьёвка без самоназначений и повторных получателей. Результат сохраняется, состав после жеребьёвки фиксируется.
- Переключение участников для демонстрации и открытие получателя в конверте.
- Подбор из 36 подарков: бюджет и исключения — обязательные фильтры, интересы и форматы — ранжирование.
- Объяснение рекомендаций, следующая подборка, поиск, категории и сортировка.
- Сохранённые идеи, выбранный подарок и последовательный чек-лист.
- Сохранение языка и игры; экспорт и восстановление JSON-копии с проверкой структуры.
- Собственное модальное окно на HTML dialog, уведомления, раскрывающийся FAQ.

Это **локальная демонстрация**, а не защищённая многопользовательская игра. Переключение участника доступно каждому, кто открыл сайт в том же браузере; копия игры содержит все назначения. Для настоящей игры нужны серверная база и проверка доступа. Данные не синхронизируются между устройствами. Очистка данных браузера удаляет игру; используйте резервную копию.

Каталог содержит идеи, а не реальные предложения магазинов. Стоимости иллюстративные. Векторные иллюстрации нарисованы специально для проекта. Bootstrap и jQuery распространяются с исходными уведомлениями об их лицензиях в vendor-файлах.

## Как объяснить алгоритмы

**Жеребьёвка.** Получатели перемешиваются алгоритмом Фишера — Йетса. Если хотя бы один участник получил себя, попытка повторяется. Число попыток ограничено 200; запасной вариант — циклический сдвиг. Проверяются уникальность и наличие всех получателей. Список без исключений всегда допускает результат при 3–12 участниках. Генератор случайных чисел в браузере использует Web Crypto. Это не заменяет контроль доступа.

**Подбор.** Сначала исключаются подарки дороже бюджета и нежелательные категории. За каждый совпавший интерес начисляется 5 баллов, за формат подарка — 2 балла. Затем применяется сортировка по баллам, цене и ID. Объяснения формируются из фактических совпадений; проценты вероятности и искусственный интеллект не используются. Если совпадений по интересам нет, возможны варианты только по бюджету; причина указана честно.

**Хранение.** Игра хранится одним JSON-объектом в localStorage под ключом `giftquest.game.v1`. Язык хранится отдельно. При чтении данные проверяются. Сбой сохранения показывается уведомлением, а резервная копия позволяет перенести демонстрацию вручную.

**Перевод.** Оба словаря и каталог загружаются через jQuery.getJSON. При переключении языка перерисовывается интерфейс, меняются подписи, ошибки, каталог, формат чисел и дат, атрибут lang и заголовок страницы. Собственные имена и введённые участниками тексты не переводятся.

## Соответствие критериям

- Структура: 6 страниц, общее меню и контекстные переходы.
- Дизайн: единая палитра, шрифты, карточки, формы и иллюстрации.
- Адаптивность: Bootstrap grid + собственные media queries; мобильное меню.
- Доступность: labels, fieldset/legend, alt, aria-pressed/expanded/live, skip-link, видимый фокус, клавиатурное управление, учёт reduced motion.
- Bootstrap и CSS: Bootstrap grid используется для основной сетки, оформление написано отдельно.
- JavaScript и jQuery: алгоритмы, формы и проверка ввода, события, обновление DOM, загрузка JSON, FAQ и анимация открытия результата.
- Качество: логика отделена от DOM, один каталог, повторно используемые компоненты, компактные локальные SVG и обработка ошибок.
- Бонусы: загрузка JSON (+5%) и полноценная локализация (+5%). Также реализованы собственное модальное окно, поиск, уведомления и копирование текста. Максимальный общий бонус по заданию остаётся +10%; оценку выставляет преподаватель.

## Сценарий защиты на 4–6 минут

1. Главная: сформулировать задачу — организовать обмен и помочь выбрать личный подарок.
2. Создать игру: показать проверку неправильного бюджета или дат.
3. Для быстрого показа нажать «Попробовать пример»: 5 вымышленных участников с заполненными анкетами.
4. Открыть одну анкету, показать интересы, исключения и сохранение.
5. Провести жеребьёвку, переключить участника и открыть конверт. Объяснить правила распределения.
6. Показать рекомендации и причины. Сохранить идею, выбрать подарок, отметить подготовку.
7. Перезагрузить страницу: результат сохранён. Переключить язык и показать мобильную версию.
8. Завершить объяснением границ демоверсии и того, что понадобится для серверного варианта.

## Подготовка к теоретическим вопросам

- **DOM и события:** DOM — дерево элементов документа. jQuery `.on()` связывает события с обработчиками; делегирование позволяет обрабатывать созданные позже элементы.
- **localStorage и JSON:** хранилище содержит строки; JSON.stringify сериализует объект, JSON.parse восстанавливает его. Доступ ограничен браузером и origin, но не пользователем приложения.
- **Bootstrap и адаптивность:** классы row/col управляют сеткой на контрольных ширинах; собственные media queries корректируют меню, размеры и расположение элементов.
- **Проверка ввода:** ограничения HTML помогают, но бизнес-правила проверяются JavaScript; ошибки показываются рядом с полями, фокус переводится к проблеме.
- **Асинхронная загрузка:** Promise.all ждёт словарь и каталог. При ошибке показывается состояние с повторной загрузкой.
- **Безопасность текста:** пользовательские строки экранируются перед вставкой в HTML. Локальная демонстрация не выдаётся за систему с приватными аккаунтами.

## Проверки

При установленном Node.js: `node checks.cjs`. Проверяются 1000 жеребьёвок для 3–12 участников, запасной вариант, исключения и бюджет, даты, 36 идей, совпадение ключей перевода и локальные ресурсы. Для изменения данных генераторы необязательны: можно редактировать JSON напрямую.
